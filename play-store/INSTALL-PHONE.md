# Установка Barajyq на телефон

Файлы: `barajyq-0.2.0.apk` (release, подписан upload-ключом) и `barajyq-0.2.0-debug.apk` (debug).

## Способ 1 — файл
1. Передай APK на телефон (Telegram «Избранное», Google Drive, USB-кабель).
2. Открой файл → разреши «Установка неизвестных приложений» для этого источника (Настройки → Безопасность).
3. Установи.

## Способ 2 — USB + adb
1. На телефоне: Настройки → О телефоне → 7 раз тапнуть «Номер сборки» → Для разработчиков → «Отладка по USB».
2. `adb install -r barajyq-0.2.0-debug.apk` (или `barajyq-0.2.0.apk`).

Release и debug имеют разные подписи — перед сменой одной на другую удали установленную версию.

## Важно: Google Sign-In

  `E5:4B:8C:38:74:16:F5:44:7D:EC:D1:B0:6A:47:77:7A:ED:2F:6F:C0`.
- **Debug**: SHA-1 `49:56:B2:F9:69:85:F2:A6:E8:79:25:78:7B:38:83:75:8D:2C:53:93` уже зарегистрирован — для проверки входа ставь `barajyq-0.2.0-debug.apk`.
- После загрузки в Play добавь ещё SHA-1 ключа Play App Signing (Play Console → Целостность приложения).
